- [_021: entry_p_threshold](_021_entry_p_threshold.md) — **is there an entry-`p` threshold? No — and ranking by raw score doesn't pay.** The champion's calibrated `p` is quantized into a **~102-name-wide top plateau**, so every entry shares one `p` (selection within it is **alphabetical**) — no within-entry threshold at any realistic K; **regime**, not `p`, decides win/loss (bull 76% / bear 34% at constant `p`). The `p` *is* monotone **between** plateaus (the strategy already trades only the top one), and the **raw** score still orders the label *within* it (top quintile 0.32 vs 0.23 plateau avg). So a new **`--rank-by raw`** option was added & tested — and it **hits more targets everywhere but worsens drawdown & risk-adjusted return in all four cells**, blowing the sp500_20 bear from **−5.8%→−28.8%** (highest-raw = highest-beta). **Keep calibrated ranking**; the alphabetical pick is an accidental volatility diversifier. "hit-rate ≠ return," same shape as `_013`/`_014`. +2 tests.

- [_018: forward_regime_signal](_018_forward_regime_signal.md) — **it was never a lag problem: NO regime signal rescues the bear.** `_017` blamed the trend gate's lag and proposed a forward-looking signal; this builds three (realized **vol**, **drawdown**-from-high, cross-sectional **breadth** — all causal, in a new `regime_signals` module) and tests them. **All preserve the bull edge** (≥89% windows beat) **but every one is negative in the bear, the fast/leading ones WORSE** (drawdown −36%, vol −30%; breadth least-bad but still no help). Refutes the lag hypothesis → confirms `_016`'s mechanism: **there's no up-move edge anywhere in a bear to gate toward**, so any risk-on window is a bear-rally trap and faster signals just whipsaw into it. **Keep the simple SMA200 gate** (best risk/whipsaw trade-off); **regime gating is a risk-reducer not an alpha-restorer regardless of signal**. Closes the regime thread. +6 tests; registry 096–107
- [_017: regime_gate](_017_regime_gate.md) — **the regime gate is a risk-reducer, not an alpha-restorer.** Built an index-trend gate (`--regime-ma N` price>SMA-N, `--regime-slope D` MA-rising; harness-level, not in the backend-agnostic strategy) and tested "does gating to cash in a bear recover the bull-only edge?" **Half-true.** In the **bull** an SMA200 gate masks ~11% of days and **preserves the edge** (sp500_50 92%→**100%**, sp500_20 +73.7%→**+81.0%**) — free insurance. In the **bear** no gate speed (200/100/50d) rescues returns (stay coin-flip/negative): the gate **can't avoid the Jan-2022 top entries** (43 risk-on days cluster Dec'21–Apr'22 while SMA200 still *rising* off the 2021 bull — irreducible causal lag), and faster MAs whipsaw worse. Lone robust bear benefit: SMA200 cuts sp500_20 DD **−32→−22%**. **Deploy SMA200** (preserves bull edge, caps bear drawdown) but it does NOT make the strategy all-weather — `_016` stands. Same shape as `_012`'s wider-K. +5 tests; registry 084–095
- [_016: real_bear_oos](_016_real_bear_oos.md) — **the real-bear test: the edge does NOT survive a sustained bear.** Retrained both sp500 champions with a pre-bear cutoff (`--snapshot-end 2022-12-31`, train_start 2016) so the test segment is the genuinely-OOS **2022 bear** (SPX −20%, trough −25%). The consistent rolling edge **collapses to coin-flip** — 92–100% of windows beat in the bull → **53%/50%** in the bear (median excess +7–10% → **~0%**) — and **drawdowns amplify** (both **−32% to −35%** vs index ~−25%): the target event (big up-move in N days) structurally stops happening in a bear, so the model's high-p picks are just high-beta names that fall hardest. **Corrects `_010`/`_015`'s "regime-neutral" read** (dips within a bull ≠ a bear). The strategy is **bull/range-bound-only**; deployment now needs a **regime gate**, not more sizing. Registry 080–083
- [_015: cost_regime_bootstrap](_015_cost_regime_bootstrap.md) — **stress-tests the equal@K=3 champion: it holds, with one honest demotion.** **Costs** (engine `commission_fn`, new `--cost-bps`): champions barely move at 50 bps/side (9–22 trades — sp500_50 92%→92%, r1k 90%→87%), while the high-turnover prob_weight K=20 contrast (486 trades) is **destroyed** (→ **0%** beat at 25 bps). **Block bootstrap** (honest effective-N = 2–5 blocks): 95% CI excludes zero for sp500_50/sp500_20/r1k_50 (p≤0.009) but **NOT ndx40** (demoted to n.s.). **Bear sub-window**: all four beat the index in its worst drawdown, but stretches are shallow (−9% to −19%). Net: cost-robust + significant on 3/4 cells; remaining gaps are sample size + a real bear, not the strategy. **Closes the V1.x arc.**
