## Outcome context

`_279` found F19 (revenue growth) **contextually additive but not robust** — the
single both-backend window-1 winner (`20pct/100d`) failed window-2 replication with
a sign-flip on both backends. `_280` then agent-tuned the top-6 sweep candidates and
found **no robust improvement over the single-fit** (4/6 finalize on defaults, 1
shuffles within noise, 1 collapses). F19 is committed as opt-in infrastructure
(`all_fundamentals2` token) but **not promoted**. These follow-ups are therefore
low-priority curiosities, not blockers.

1. **[RESOLVED by `_280`] Single-quarter-QoQ FS-drop test.** The user asked to include
   `fund_rev_q_qoq` (single-quarter sequential QoQ) with "if it's bad FS should drop
   it." The `_279` sweep is single-fit so could not answer it, but `_280`'s agent
   loops read per-iteration feature importance and settle the question: across the
   catboost cells the **single-quarter measures (`fund_rev_q_yoy`, `fund_rev_q_qoq`)
   sit at ~zero importance** — CatBoost's importance-FS drops them on its own — while
   the TTM-QoQ sequential z-score (`fund_rev_ttm_qoq_xs_zscore`) is the one F19 column
   the models lean on. FS drops the single-quarter QoQ, as hoped.

2b. **[low priority, un-selectable] Window-2 of the `20pct_100d` depth-4 arm.** `_280`'s
   one window-1 book gain (`20pct_100d` cb depth-4: @1 0.22→0.41, @5 0.53→0.60) is
   **not selectable from in-loop signals** (the loop's own pick, the l2-1 eval-leader,
   is worse on test) and is a **partial-K shuffle** (loses @3/@20), so it did not earn
   a second-window pass. If ever revisited, run the depth-4 config on the `_278` window
   2 (`train_start: 2019-07-01`) — but the prior is "un-actionable noise."

2. **[low priority] Single-backend F19 winners.** `_279` window 1 had single-backend
   "wins" (xgb: `10pct_10d`, `10pct_50d`, `20pct_5d`, `40pct_25d`, `50pct_25d`; cb:
   `20pct_50d`, `40pct_100d`, `40pct_200d`, `50pct_100d`). Per the `_276`/`_278`
   lesson these are window-noise-prone (the both-backend winner itself failed window
   2), so none were confirmed. If F19 is ever revisited, a two-window pass on the
   strongest single-backend cells (`20pct_5d` xgb Δ@10 +0.087; `50pct_25d` xgb Δ@10
   +0.072) would confirm/refute — but the prior is strongly "noise."

3. **[deferred] Non-revenue growth features.** If a growth family is ever pursued
   again, the natural extensions beyond revenue: net-income / EPS YoY, FCF YoY,
   margin *trend* (Δ net-income/revenue), and gross-margin once
   `us_fundamentals` gains the line item (`data_pipelines` V3_TBD). Gated on F19
   showing *any* robust signal first — which `_279` says it does not.

## What replicated instead

The standing V1.7 read holds: on these sp500 cells the robust lever is the
**backend** (CatBoost beats xgboost on test AUC across the long-horizon cells,
`_278`), not additional fundamentals feature families (F17-macro `_264`, long-horizon
F18 `_278`, and now F19 revenue-growth `_279` all failed second-window confirmation)
— and not more **tuning** either: `_280` showed agent-protocol finetuning of the F19
top-6 anti-selects the test top-book (val/eval/test-AUC all move opposite to the
book), so the untuned single-fit is the ceiling. The `V1.7_TBD` §6 CatBoost pass over
the deployed champion cells remains the highest-value cheap experiment.
