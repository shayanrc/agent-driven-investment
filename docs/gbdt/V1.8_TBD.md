## Outcome context

`_279` found F19 (revenue growth) **contextually additive but not robust** — the
single both-backend window-1 winner (`20pct/100d`) failed window-2 replication with
a sign-flip on both backends. F19 is committed as opt-in infrastructure
(`all_fundamentals2` token) but **not promoted**. These follow-ups are therefore
low-priority curiosities, not blockers.

1. **[low priority] Single-quarter-QoQ FS-drop test.** The user asked to include
   `fund_rev_q_qoq` (single-quarter sequential QoQ) with "if it's bad FS should drop
   it." The `_279` sweep is **single-fit (`max_iterations: 1`) — it does NO
   importance pruning**, so it cannot answer whether FS drops the (seasonally-noisy)
   single-quarter QoQ. A full FS+HP loop (default or agent) on the `all_fundamentals2`
   pool for a cell or two would show which of the 4 growth measures survive
   importance pruning. Only worth doing if F19 is revisited — with the family
   non-robust overall, the per-column FS survival is academic.

2. **[low priority] Single-backend F19 winners.** `_279` window 1 had single-backend
   "wins" (xgb: `10pct_10d`, `10pct_50d`, `20pct_5d`, `40pct_25d`, `50pct_25d`; cb:
   `20pct_50d`, `40pct_100d`, `40pct_200d`, `50pct_100d`). Per the `_276`/`_278`
   lesson these are window-noise-prone (the both-backend winner itself failed window
   2), so none were confirmed. If F19 is ever revisited, a two-window pass on the
   strongest single-backend cells (`20pct_5d` xgb Δ@10 +0.087; `50pct_25d` xgb Δ@10
   +0.072) would confirm/refute — but the prior is strongly "noise."

3. **[deferred] Non-revenue growth features.** If a growth family is ever pursued
   again, the natural extensions beyond revenue: net-income / EPS YoY, FCF YoY,
   margin *trend* (Δ net-income/revenue), and gross-margin once
   `us_fundamentals` gains the line item (`data_pipelines` V3_TBD). Gated on F19
   showing *any* robust signal first — which `_279` says it does not.

## What replicated instead

The standing V1.7 read holds: on these sp500 cells the robust lever is the
**backend** (CatBoost beats xgboost on test AUC across the long-horizon cells,
`_278`), not additional fundamentals feature families (F17-macro `_264`, long-horizon
F18 `_278`, and now F19 revenue-growth `_279` all failed second-window confirmation).
The `V1.7_TBD` §6 CatBoost pass over the deployed champion cells remains the
highest-value cheap experiment.
