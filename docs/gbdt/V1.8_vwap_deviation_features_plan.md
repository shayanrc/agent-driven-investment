# V1.8 — VWAP-deviation feature family (F20) + ± fundamentals sweep

**Requested by the user.** Add a **VWAP-deviation z-score** feature family, build models
**with and without fundamental features** that use it, run a matched sweep, then
agent-finetune the top candidates. Mirrors the F17-macro / F18-F19-fundamentals arc
(`_262`–`_280`): a new opt-in family, a clean matched A/B sweep, and a two-window
robustness verdict — NOT an automatic promotion.

## F20 — the feature family (shipped in this branch)

Daily OHLCV has **no intraday VWAP**, so F20 uses a causal (C1) daily proxy:

- `TP = (high + low + close) / 3` (typical price)
- `VWAP_N = Σ(TP·vol) / Σ(vol)` over the trailing N bars (per-ticker, `min_periods=N`)
- `vwap_dev_N = close / VWAP_N − 1` — signed relative stretch of price above/below where
  volume actually transacted
- `vwap_dev_zscore_N` — per-stock trailing z-score of `vwap_dev_N` over its own N-window
- `vwap_dev_xs_zscore` / `vwap_dev_xs_rank` — cross-sectional (universe-relative,
  asset-agnostic) z/rank of the 20-day deviation each date

14 columns total (`N ∈ {5,10,20,50,100,200}`). Every window is strictly trailing incl.
the current bar (same causality as F1–F16). Asset-agnostic (no per-stock constants).

**Opt-in tokens** (default `"all"` stays byte-identical, locked by a test):
- `all_vwap` = `_ALL_FAMILIES + ("F20",)` — technical + VWAP (**no** fundamentals)
- `all_fundamentals_vwap` = `_ALL_FAMILIES + ("F18", "F20")` — technical + F18 + VWAP

## The sweep (task 16)

Matched **single-fit** A/B (max_iterations 1, default HP, date_aligned
`train_start 2019-01-01`, same snapshot 2026-07-06 as `_279` so it's directly
comparable), across the 17 sp500 lattice cells × four feature arms:

| arm | token | reads |
|---|---|---|
| base | `all` | — |
| +vwap | `all_vwap` | — |
| +fund | `all_fundamentals` | valuation panel |
| +fund+vwap | `all_fundamentals_vwap` | valuation panel |

The arms differ ONLY in `candidates`, so per-cell deltas are clean
(`[[project-gbdt-macro-features-f17]]` rule). This reads BOTH the **VWAP marginal**
(`vwap − base`) AND whether **VWAP stacks on fundamentals** (`fund+vwap − fund`).

**Backend: xgboost-only** (68 fits), by the user's decision 2026-07-07. The generator
emits an 8-arm {xgb, cb} factorial (136 specs, all committed) but the run was trimmed to
the 4 xgboost arms: measured warm-fit cost was ~7 min (xgb) vs ~9.3 min (cb), and the
backend question is already settled — `_277`/`_278` found CatBoost wins long-horizon test
AUC. Dropping the cb half ~halved wall-clock (~19 h → ~8 h) while keeping the full
VWAP-marginal + fund-stack read across all 17 cells. The cb arms can be run later off the
committed specs if a cell warrants a backend check. Tooling:
`scripts/gbdt/gen_vwap_sweep_specs.py` + `run_vwap_sweep.sh` (resumable — skips arms whose
`metrics.json` exists). Register every row in `results/gbdt/data/r_precision_at_k.csv`.

## The finetune (task 17)

From the VWAP-arm sweep rows, take the **union of top-3-by-R-p@3 and top-3-by-AUC** cells
(the `_280` recipe) and run `agent_file_protocol` FS+HP finetunes (winner's-curse
discipline, `[[project-gbdt-tuning-playbook]]`; iter 0 == the sweep single-fit so every
delta is tuned-vs-untuned). Watch for the `_276`/`_280` anti-selection pattern
(val/eval/test-AUC gains that flatten the test top-book).

## Success criteria / verdict (task 18)

The bar is **two-window robustness**, not a single-window win — F17-macro (`_264`) and
long-horizon F18 (`_278`) and F19 (`_279`) all looked additive on one window and failed
the second. A VWAP edge is adopted only if it replicates on an independent date-aligned
window. Champion / `/daily-predictions` changes remain a **separate human decision**.
