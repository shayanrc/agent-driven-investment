**Branch:** `nifty500-canonical-scan` · **Worktree:** `wt-nse-valuation`

**Task:** #55 (re-run nifty500 `_285` lattice fbase/ffund on canonical periods, NSE parity) + finetune the best few.

## Why

`_285` established the nifty500 base-vs-fund A/B lattice but was invalidated by the
NSE-fundamentals coverage cliff: `in_fundamentals` (F18-IN) only begins ~2019, so a
2015-anchored (canonical) train trains the fund arm with F18 absent for ~40% of the
window. The base (technical) arm was never confounded — the 2015 back-extend fixed
technical features + target. See `[[project-in-fundamentals-coverage-cliff]]`.

The user chose the **backfill-first** path: de-confound F18-IN with a screener.in
pre-2019 annual backfill, THEN run BOTH arms fully on the canonical periods so the
fund read is clean and on the canonical grid (parity with the sp500 `_288` retrains).

single fit `max_iterations: 1`) — only `features.candidates` differs:
- **fbase** `all_calendar2` (F1–F16 + F21 seasonality)
- **ffund** `all_fundamentals_calendar2` (+ F18-IN valuation columns)

Aggregate → `results/gbdt/data/r_precision_at_k.csv` rows (`*_canon` suffix) + memo
`docs/gbdt/_NNN_nifty500_canonical_scan.md`. Judge on the **book** (R-p@K), not AUC.
