## 1. Motivation

Two related reproducibility holes:

**(a) Trailing-anchor carve silently re-defines cells on rerun.** `carve_single_fold` (`src/gbdt/train.py:66-93`) takes each ticker's last 1,500 rows. When the cache grows by N new bars, `tail = arange(len-1500, len)` slides forward by N → yesterday's "eval" becomes tomorrow's "val" → the canonical CSV row silently measures something different on rerun.

**(b) `results/gbdt/data/r_precision_at_k.csv` has no calendar provenance.** A reader cannot tell what calendar window each row's metrics were computed on; a downstream backtester wanting to validate findings has no native way to ask "what dates was this model evaluated on?"

This plan adds an opt-in **`mode: date_aligned`** carve + eight calendar-date columns to the canonical CSV.

## 2. Goal + non-goals

**Goals**

- New runs are reproducible across cache growth — adding new bars past the test window leaves segments bit-identical.
- Every row in `r_precision_at_k.csv` self-describes its (train, val, eval, test) calendar windows.
- A backtester can use `test_end + 1` as a clean out-of-sample start without external lookup.
- Migration is **opt-in**: existing specs + the 38 trailing-anchor CSV rows continue to work; date-aligned coverage accumulates organically.
- Side-effect: bug #129 / task #228 ("H≥100 test window eaten by horizon") disappears for any date-aligned cell where the cache spans `train_start + 1,500 + H` trading days.

**Non-goals**

- Forced rerun of the existing 38 cells under date-aligned (no compute spent at this PR).
- Edits to existing per-cell memos / JSON sidecars (per D8).
- A `split_mode` enum column in the CSV (the date columns carry the info implicitly).
- Changes to FS+HP loop logic, metric formulae, or backend code paths.

## 4. Carve logic — concrete spec

### 4.1 `SplitSpec` (`src/gbdt/train.py:43-52`)

```python
@dataclass
class SplitSpec:
    mode: Literal["trailing", "date_aligned"] = "trailing"
    train_rows: int = 800   # interpreted as trading-day duration when mode == "date_aligned"
    val_rows: int = 400
    eval_rows: int = 200
    test_rows: int = 100
    train_start: date | None = None   # required when mode == "date_aligned"; defaults to 2019-01-01 in runner
    min_train_rows_per_ticker: int = 200   # = max(lookback_windows)
```

### 4.2 `carve_universe_aligned(panel, split, universe_calendar)`

```python
# 1. Compute calendar segment boundaries on the universe's canonical trading calendar.
cal = universe_calendar  # e.g. NYSE for sp500/nasdaq/russell1000; NSE for nifty*
days_train_start = cal.searchsorted(split.train_start, side="left")
days_val_start   = days_train_start + split.train_rows
days_eval_start  = days_val_start + split.val_rows
days_test_start  = days_eval_start + split.eval_rows
days_test_end    = days_test_start + split.test_rows - 1  # inclusive

dates = {
    "train_start": cal[days_train_start],   "train_end": cal[days_val_start  - 1],
    "val_start":   cal[days_val_start],     "val_end":   cal[days_eval_start - 1],
    "eval_start":  cal[days_eval_start],    "eval_end":  cal[days_test_start - 1],
    "test_start":  cal[days_test_start],    "test_end":  cal[days_test_end],
}

# 2. Per-ticker membership.
for t in tickers:
    sub = panel.xs(t, level="ticker").sort_index()
    for seg in ("train", "val", "eval", "test"):
        mask = (sub.index >= dates[f"{seg}_start"]) & (sub.index <= dates[f"{seg}_end"])
        n_valid = mask.sum()   # features.py NaN-propagated already
        gate = split.min_train_rows_per_ticker if seg == "train" else 1
        if n_valid >= gate:
            segs[seg][t] = np.flatnonzero(mask)
        # else: ticker excluded from this segment
```

### 4.3 Dispatch in `carve_single_fold`

```python
if split.mode == "date_aligned":
    return carve_universe_aligned(panel, split, universe_calendar)
return carve_trailing(panel, split)   # existing logic
```

### 4.4 Universe trading calendar

- US universes (nasdaq100, sp500, russell1000): NYSE calendar via `pandas_market_calendars.get_calendar("NYSE")`.
- NSE universes (nifty50, nifty100, midcap150, nifty500, sectoral, thematic): NSE calendar via `pandas_market_calendars.get_calendar("NSE")`.
- Universe → calendar mapping in `configs/gbdt/default.yaml::universes::<name>::calendar` (new field, defaults inferred from universe name prefix for back-compat).

### 5.3 Backfill semantics (existing 38 trailing-anchor rows)

For each existing CSV row, walk artifacts in this search order:

1. Main checkout: `results/gbdt/experiments/<cell_id>/`.
2. Active worktrees: iterate `git worktree list --porcelain`, look in each for `results/gbdt/experiments/<cell_id>/`.

If found: read `predictions.parquet`, compute MIN/MAX date per segment (calendar union across tickers), write to CSV. If not found: leave 8 columns empty + log to `results/gbdt/data/v1.4_backfill_log.json` with the cell id + reason.

## 6. Pre-flight (`/gbdt-experiment` Phase 0)

Adds a check after the existing cache-coverage / SQLite-WAL / disk-space checks.

```
if split.mode == "date_aligned":
    # Sub-case A — universe-level shortfall
    needed_end = cal[days_test_end + horizon]
    if needed_end > today:
        REFUSE("test_end + H = {needed_end} is past today {today}. ...")
    # Sub-case B — per-ticker right-edge staleness
    deficient = []
    for ticker in universe:
        latest = cache_latest_date(ticker)
        if latest < needed_end:
            for attempt in range(3):
                ok = try_fetch(ticker, end=today, back_extend=False)
                if ok: break
                if not is_transient_error: break
                sleep(1 << (2 * attempt))   # 1s, 4s, 16s
            latest = cache_latest_date(ticker)
            if latest < needed_end:
                deficient.append((ticker, latest, needed_end, last_error_type))
    if deficient:
        REFUSE(format_deficient_table(deficient))
    # Sub-case C — per-ticker history depth: auto-handled by membership gate
```

## 8. Acceptance criteria

- **A1**: A cell run under `mode: date_aligned, train_start: 2020-01-01` (override) produces `metrics.json` with all 8 segment-date fields populated as ISO strings + the three per-ticker sidecar fields populated.
- **A2**: The cell's row in `r_precision_at_k.csv` carries all 8 date columns matching `metrics.json`.
- **A3**: Re-running the same spec on the same cache produces bit-identical date columns + per-segment row counts.
- **A4** (**cache-growth invariance test — the whole point**): adding 30 synthetic new cache bars after the run, then re-running, produces bit-identical date columns + row counts.
- **A5**: A trailing-anchor cell's backfilled CSV row carries dates matching the corresponding `predictions.parquet`'s MultiIndex per-segment endpoints (calendar union across tickers).
- **A6**: Pre-flight refuses to start when cache is short, lists the deficient tickers + days-short + last-error-type, suggests a remediation path. Auto-retries happen on transient errors.
- **A7**: Existing trailing-anchor specs continue to run unchanged (no behavior diff on `nasdaq100_up_10pct_25d_dd5pct` rerun in trailing mode). Info-log nudge appears once per run.
- **A8**: Backfilled `r_precision_at_k.csv` + `regenerate_r_precision_at_k_csv.py` are round-trip idempotent.

## 9. Migration story

- Default `mode: trailing` → existing 38 CSV rows + sweep YAMLs continue working.
- Backfill populates the 8 date columns for the 38 existing rows (calendar union per segment) where the artifact dir is found across main + active worktrees. Unbackfillable rows: empty cells + logged manifest.
- New work opts in via `split.mode: date_aligned` + (optional) `split.train_start`; default anchor `2019-01-01` applies if omitted.
- #228 (H≥100 rerun) lands as date-aligned natively → its 19 rows are reproducible by construction.
- V1.5_TBD: flip the default to `date_aligned` once organic coverage is high enough that trailing rows are a minority.

## 10. Risks + mitigations

| Risk | Mitigation |
|---|---|
| Backfill can't extract per-segment dates from old `predictions.parquet` (artifact-layout drift) | Audit one cell from each era (#147, #195, #211, #224) before writing backfill; fallback to `iterations.jsonl` if predictions.parquet lacks per-segment markers. |
| Pre-flight false-positive (legitimately-young ticker excluded from train) | Membership gate handles this auto: ticker excluded from train only; appears in val/eval/test where it has valid features. No REFUSE. |
| `train_start` falls on a non-trading day | `searchsorted(side="left")` advances to next trading day. Document in EXPERIMENT_SPEC.md. |
| Per-ticker calendar drift (US holiday vs NSE holiday for cross-market panel) | Each universe declares one calendar; cross-market panels are not supported in v1 (cells are universe-scoped). |
| Backfill mis-matches CSV rows to artifact dirs | Backfill verifies `(universe, direction, threshold, horizon)` from artifact's `spec.yaml` snapshot before writing. Mismatches → skip + log. |
| `pandas_market_calendars` not installed | Add to `pyproject.toml`; uv-sync as part of P1. |
